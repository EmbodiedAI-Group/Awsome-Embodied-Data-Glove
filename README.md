## 各产品详情与链接说明

### 1. MANUS — Metagloves Pro Haptic / Quantum Metagloves

- **官网**：https://www.manus-meta.com
- **产品介绍**：Metagloves Pro Haptic 采用 EMF 电磁场追踪技术，实现 25 自由度全解剖学手部追踪，毫米级精度，无遮挡无漂移。每根手指配备独立的 LRA 线性谐振振动马达，支持 256 级振动强度控制[reference:0]。Quantum Metagloves 已售罄并停产，Metagloves Pro 是其直接继任者。

### 2. Diver-X — ContactGlove3 / ContactGlove3 Pro

- **官方商店**：https://store.diver-x.jp/en
- **具体报道**：[IT之家报道](https://www.ithome.com/0/969/999.htm)
- **产品介绍**：基于电磁场追踪方案，中位数 0.5mm 的位置误差和 0.4° 的方向误差，回报率 100Hz，延迟低至 30ms。ContactGlove3 Pro 专为机器人远程操作设计，原生支持 ROS 2 / C++ / Python SDK。

### 3. 帕西尼（PaXini）— PXCap V / PXCap III

- **官方商城**：https://mall-test.paxini.com
- **具体报道**：[百度百科](https://baike.baidu.com/item/PXCap%20%E2%85%A4/67963505)、[Leaderobot报道](https://leaderobot.com/news/8078)
- **产品介绍**：PXCap V 是全球首款全五指无盲区触觉覆盖的穿戴式数据采集设备，82 自由度，内置 30 个六维触觉模组，触觉点数达 3015 个。PXCap III 为三指数据采集手套，触觉力感知精度 0.1N，关节绝对精度 ±0.15°。

### 4. SenseGlove — SenseGlove R1

- **官网**：https://www.senseglove.com
- **产品介绍**：专为遥操作人形机器人设计，融合主动力反馈、毫米级手指追踪精度和振动触觉反馈。1kHz 采样与控制回路，4DoF 主动力反馈[reference:1]。

### 5. 手智创新 — HANDX 智能触觉手套

### 6. 尧乐科技 — 柔性织物数据手套

- **具体报道**：[IT168报道](https://m.it168.com)
- **产品介绍**：将传感功能直接融入织物结构，采用“金属纱线+三明治矩阵”架构。最高每平方厘米 100 个感应点，计划 2026 年 8 月正式发布。

### 7. 鸿磐（Honpine）— EG 机械外骨骼手套 / 遥操作手套

- **官网**：https://cn.honpine.com
- **具体产品页**：[高精度遥操作机械外骨骼手套](https://cn.honpine.com/products/High-Precision-Control-Industrial-Robot-End-Effector/Dexterous-Robot-Hand/High-Precision-Teleoperation-Mechanical-Exoskeleton-Glove.html)
- **产品介绍**：配备 15 个磁编码器，每根手指 3 个，覆盖外展、掌指关节和远端指间关节三个维度。16-bit 高精度编码器，采用 ESP-NOW 无线传输，通信频率 20~30Hz[reference:2]。



## 二、数据采集手套主要类型

| 类型 | 技术路线 | 代表产品 | 特点 |
|------|---------|---------|------|
| **电磁追踪手套** | EMF 电磁场定位 | MANUS Metagloves Pro、Diver-X ContactGlove3 | 毫米级精度，无遮挡问题，无累计漂移 |
| **柔性织物传感手套** | 分布式柔性传感阵列 | 手智创新、尧乐科技、人本国际 | 穿戴舒适，可大规模部署，成本较低 |
| **惯性动捕手套** | IMU 惯性传感器 | VDSuit-Full、mHand Pro | 无线便携，适合大范围运动 |
| **力反馈手套** | 主动力觉反馈 | SenseGlove R1、HaptX Gloves | 可感受抓握力度，适合遥操作 |
| **光学追踪手套** | 红外/视觉标记 | CyberGlove、PhaseSpace | 高精度，但易受遮挡影响 |
| **外骨骼手套** | 刚性连杆+编码器 | 鸿磐 EG 外骨骼手套 | 精度高，无漂移，但体积较大 |
| **开源学术手套** | 多种传感融合 | OSMO、ART-Glove | 完全开源，适合学术研究 |

> 数据采集手套按技术路线可分为以上几类，不同路线在精度、成本、穿戴舒适性和适用场景上各有侧重。电磁追踪手套精度高但价格昂贵，柔性织物手套成本较低适合大规模部署，外骨骼手套精度高但体积较大，开源学术手套适合科研验证。
